Components

One live example per component section in STYLEGUIDE.md, in the same order. Where a js/ui.js helper renders the component, the markup below was produced by importing and calling that helper just now — the same function the live app calls on every render.

Bottom tab bar

No js/ui.js helper renders this — it's hand-authored in index.html — so it's reproduced here verbatim (contained in a bounded box; the real one is position: fixed to the viewport).

Event row

Built by calling eventsView() from js/views/events.js just now and taking its first .event-row — including its per-card toggle, in whatever state your browser's saved selection currently has it (nothing on this page ever writes to that selection).

Events tab: grouped by discipline

Built by calling the real eventsView() just now and taking its category <h2> headings, in order (Track / Jumps / Throws / Bonus) — the same four <section>s the live Events tab renders.

Per-card Tonight toggle

Both states, produced by two direct calls to tonightToggleButton() from js/ui.js — a 44×44 icon-only circle. The accessible name (aria-label) is identical in both; the glyph (+ / ✓) and border style (dashed / solid) are the two required non-colour signals that change (the fill also changes to a solid --color-success green when on, but colour is never the only signal — see STYLEGUIDE.md).

Event Detail "Add to tonight" CTA

Both states, produced by two direct calls to tonightCtaButton() from js/ui.js — the same per-event Tonight state as the toggle above, reusing the exact same data-action="toggle-tonight" click handler.
