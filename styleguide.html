Real navigation (hash changed): scrolls to top, moves focus to the new #page-title.

State-only re-render (tonight:change event — mode switch, per-card toggle, picker open/close/save): repaints #view only; interactions.js places focus deliberately afterwards. See STYLEGUIDE.md for the full rule.

Sync rule. A change to a token value, a type-scale row or a component pattern requires the same change here and in STYLEGUIDE.md, in the same edit — see the checklist at the top of that file. Colour swatches read live from css/tokens.css custom properties, so a token value change updates itself; a token being added or removed still needs a swatch added or removed by hand.

This page is not a router route — a fifth tab-bar entry would breach the exactly-four-tabs rule — so it carries its own landmarks (header, main, a skip link) rather than reusing index.html's.
